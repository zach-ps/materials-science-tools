# materials-science-tools

Interactive educational tools and scientific visualizations for teaching materials science and engineering concepts.

Created by:

**Sachie Prabuddha Sathurusinghe, PhD**  
Department of Civil Engineering  
Faculty of Engineering  
University of Peradeniya  
Sri Lanka

---

# Overview

This repository contains interactive teaching resources for:

- Phase diagrams
- Dislocations and crystal defects
- Strengthening mechanisms
- Crystal structures
- Materials characterization
- Ashby charts
- Engineering materials education

The tools are primarily developed using:

- Python
- Plotly
- SVG vector graphics
- GitHub Pages

---

# Current Interactive Tools

## Phase Diagrams

### Pb-Sn Phase Diagram

Interactive Pb-Sn eutectic phase diagram with:

- SVG-based curve extraction
- Interactive tie-line visualization
- Composition and temperature extraction
- Hover-based coordinate inspection
- High-resolution vector curves
